# ARCISTA ホームページ

佐賀県上峰町の眉・脱毛プライベートサロン ARCISTA（アルシスタ）のウェブサイトです。
ビルド不要の静的サイト（HTML / CSS / JavaScript）で、GitHub Pages などにそのまま公開できます。

## ページ構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ホーム |
| `eyebrow.html` | 眉スタイリング |
| `lks.html` | LKS make（LKS make 眉 / LKS make リップ） |
| `hair-removal.html` | 脱毛メニュー（都度払い / 全身脱毛コース） |
| `other.html` | その他のメニュー（ドライヘッドスパ / IPL光フェイシャル） |

- `css/style.css` … 全ページ共通のデザイン（色・フォントは冒頭の `:root` で変更できます）
- `js/main.js` … スマホ用メニューの開閉、スクロール時の表示アニメーション
- `images/` … 写真・ロゴ

## 内容を変更するとき

- 料金や文章は各 HTML ファイルを直接編集します。
- ヘッダー・フッター・予約ボタン・店舗情報は5ページそれぞれに同じ内容が入っています。変更するときは5ファイルすべてを直してください。
- WEB予約と公式LINEのリンク先は、各ページの `WEB予約` / `LINE` のリンク（`href`）で指定しています。

## 確認方法

`index.html` をブラウザで開くだけで確認できます。
